Prompt 1 — Replit (Express + React + Vite + Tailwind)

Title: Crude & Diesel Haul Rate Calculator (Keep API key server‑side)

Plain‑English: what to build and how it works

Build a web app that helps a crude‑oil and diesel trucking operator decide what to charge for a given haul. The app lets me:

Upload spreadsheets of my pickup and drop‑off locations (with lat/long), optional route overrides, and my default settings (target hourly earnings, default MPH, base yard, typical pickup/drop‑off/queue times).

Pick a pickup and drop‑off site from those lists, choose load type (crude = paid per barrel, diesel = paid per gallon), enter how many units I’m hauling, set my average MPH when loaded and empty, and set the minutes I usually spend at pickup/drop‑off including queue and buffer for traffic.

The app asks Google Maps for multiple route options between those coordinates. We only use Google’s distance (miles) and the map polyline—we ignore Google’s time because I want to use my own MPH.

For every alternative route, the app calculates: driving hours using my MPH, adds my on‑site minutes and buffer, and multiplies by my target $/hour. From that required revenue it computes a suggested price: $ per barrel for crude or $ per gallon for diesel. It also shows $ per mile (total) and $ per mile (loaded).

I can include deadhead legs from my base yard to pickup and from drop‑off back to base. Empty legs can reuse the same miles or be computed separately. I can also save scenarios, export to CSV/PDF, and see a map with each alternative highlighted.

Names stay human‑friendly (e.g., “Pentland Station”). The app auto‑generates a safe internal ID (UPPER_SNAKE_CASE) from the name during import. I never need to type underscores.

Security: My Google Maps API key must never appear in the browser. The React client calls an Express server route which injects the key and talks to Google.

Technical build spec
Stack

Frontend: React 18 + TypeScript + Vite + Tailwind (shadcn/ui optional)

Backend: Node/Express inside Replit

Secrets: GOOGLE_MAPS_API_KEY stored in Replit Secrets; never sent to the client

Persistence: JSON files in /data (locations.json, config.json, overrides.json, routeCache.json, scenarios.json). Provide functions to swap to SQLite later.

Pages

Upload/clean rules

Accept CSV/XLSX for: locations_template_v2_no_id.csv, routes_overrides_template.csv, app_config_template.csv

Column mapper allows arbitrary headers; map to expected keys

Auto‑ID: if location_id missing, derive from name as UPPER_SNAKE_CASE (spaces→_, strip non‑alphanumerics)

Validate CA bounds: 32–42 lat, −125 to −114 lon; if lon > 0, suggest negation

Reject rows without name/role/lat/lon; show error CSV

Express routes

POST /api/routes → body: { origin:{lat,lon}, destination:{lat,lon}, waypoints?:[], avoid?:{tolls:boolean,ferries:boolean}, alternatives:true }

Read GOOGLE_MAPS_API_KEY from env

Call Google Directions (alternatives=true)

Compute miles = total meters / 1609.34

Return { routes:[{ id, summary, miles, polyline }] }

Cache results in routeCache.json (TTL 30 days)

Calculator formulas
drive_time_hr = (d_loaded_mi / mph_loaded) + (d_empty_mi / mph_empty)
work_time_hr  = (pickup_work + dropoff_work + pickup_queue + dropoff_queue + buffer) / 60
total_hours   = drive_time_hr + work_time_hr
required_revenue = total_hours * hourly_target


// Pricing
if load_type == 'crude':
  rate_per_unit = required_revenue / barrels_loaded
else if load_type == 'diesel':
  rate_per_unit = required_revenue / gallons_loaded


rate_per_mile_total  = required_revenue / (d_loaded_mi + d_empty_mi)
rate_per_mile_loaded = required_revenue / d_loaded_mi
Deadhead logic

If include_deadhead=true:

Base→Pickup (empty), Drop‑off→Base (empty)

If assume_symmetric_route_for_empty=true, use same miles as loaded route for return legs; otherwise call /api/routes for each empty leg

UI specifics

Inputs left panel; results right panel with table of alternatives (sortable); map shows selected polylines

Unit labels switch automatically: crude→barrels, diesel→gallons

Highlight the lowest rate_per_unit in green

Buttons: Save Scenario, Export CSV, Export PDF (with map snapshot)

Acceptance tests

Upload locations without location_id → IDs auto‑generated; positive longitudes are flagged with a fix suggestion

Selecting a pair with alternatives shows ≥2 routes; times computed from my MPH, not Google’s

Changing hourly target instantly updates $ per barrel/gallon

Toggling deadhead changes empty miles/time and pricing

Saved scenario reopens identically

API key never appears in network logs or client code
