API Endpoints
GET
/get-placements/{site-id}
Fetch media placements for a specific site

Headers
x-api-key: YOUR_API_KEY
Query Parameters
page_url (optional): Filter by specific page URL (e.g., /about)
slot (optional): Filter by placement slot (e.g., header, hero, footer)

WordPress Plugin
Copy
<?php
// Example WordPress plugin integration
function get_cms_placements($site_id, $api_key, $page_url = null) {
    $url = "https://uoaxuhyocsgyzrwcghoj.supabase.co/functions/v1/get-placements/" . $site_id;
    
    if ($page_url) {
        $url .= "?page_url=" . urlencode($page_url);
    }
    
    $response = wp_remote_get($url, [
        'headers' => [
            'x-api-key' => $api_key
        ]
    ]);
    
    if (is_wp_error($response)) {
        return false;
    }
    
    return json_decode(wp_remote_retrieve_body($response), true);
}

// Usage in theme
$placements = get_cms_placements('your-site-id', 'your-api-key', '/');
foreach ($placements['placements'] as $placement) {
    if ($placement['slot'] === 'header') {
        echo '<img src="' . esc_url($placement['media']['url']) . '" alt="' . esc_attr($placement['media']['title']) . '">';
    }
}
?>
Integration Guide
1. Get Your API Key
Navigate to your site in the dashboard and click the API key icon to generate a new key with the required scopes.

2. Choose Your Integration Method
Direct API calls: Use fetch/curl to get placements in your JavaScript/backend
Webhook integration: Set up automatic updates when placements change
CMS plugins: Use our WordPress/Drupal plugins for easy integration
3. Implement Caching
Cache API responses for 5-10 minutes to improve performance and reduce API calls.

4. Handle Errors Gracefully
Always implement fallbacks when the API is unavailable to ensure your site remains functional.
